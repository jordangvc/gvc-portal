What changes below 900px
The rail becomes a drawer

Full-screen, .rail.is-open. It covers the hamburger that opened it, so it needs the .phone-only close button — without one the user is trapped.

The tab bar appears

Four destinations, safe-area padded. Render it in every shell — it hides itself above 900px.

Chip groups scroll sideways

Each .chipset__opts becomes one swipeable row with snap points instead of a wrapping wall four rows deep.

Nested scrollers release

.scroll-rows and .scroll-tall drop their caps so the page is the only thing that scrolls. Two scrollbars in a moving truck is unusable.

Measuring rows go two-up

Dimensions and board on line one; label, tags and actions on line two. Seven controls in one row is unusable at 390px.

Targets grow

Everything interactive hits 44px, primary actions 48px, checkboxes 20px. Chips gain horizontal padding and step up to --text-sm.

The rule that matters most on a phone

Every card action deep-links to the exact job, invoice or output — never to the tool's landing page. Two taps, not eight. It is the single biggest usability win on mobile and it costs nothing but routing.
