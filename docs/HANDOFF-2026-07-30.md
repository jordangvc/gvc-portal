## 6. Hard-won gotchas — these cost real time to find

**Monday**
- **Mirror and board-relation columns return `text = null`.** The readable value
  is in `display_value`. Every Operations context column is one of those types.
  This silently blanked the whole Job Check header until caught by testing
  against the live board.
- **Monday cannot write to a mirror column.** Writes fail or no-op.
- Column ids are opaque and lie about type: `numbers18` ("Estimate #") holds
  free text. Always confirm with `get_board_info` before coding against a column.
- Board activity is the honest usage signal. Job Check was pointed at the wrong
  board for a week; 14 days of activity settled it in one query (Operations 788
  column edits vs 29 on the columns Job Check was writing).

**Google / Drive**
- **A Drive folder you can't see returns an EMPTY LIST, not an error.** Identical
  to "nothing matched". Probe the parent folder first and report `no_access`
  separately, or you'll send someone hunting a filing mistake that never happened.
- Adding a Secret Manager **version does nothing until a new revision starts.**
  `min-instances=1` keeps the old value mounted. Always bounce the revision.
- Resetting a Google account password **revokes every Gmail refresh token** for
  it. This will recur; the fix is re-minting the token, not a code change.

**Slack**
- Post by **channel ID**, never name. And the bot must be an explicit **member**
  of every channel — `chat:write.public` does not carry it. A missing invite fails
  **silently**.
- A Slack notice is verified **only** by a delivered message. Config presence has
  produced a false "verified" three separate times in this project's history.

**Windows / this box**
- `gcloud` is not on the Bash tool's PATH. Use PowerShell with the full path.
- `gcloud.cmd` mangles quoted JSON in `--message-body`; use
  `--message-body-from-file`.
- Set `PYTHONIOENCODING=utf-8` or any script printing `→`/emoji dies on cp1252.
- Bash heredocs break on apostrophes in data. Use the Write tool for data files.
- Oversized MCP results are saved to a file and only a short notice returns —
  so paginating a big board is nearly free in context. Process the files with
  Python. **Check the `board.id` in each saved file before combining them** — I
  once mixed an Invoices-board page into a Bid Board analysis and inflated the
  counts.

**Smoke-testing auth-gated routes**
An existing route returns **303** (redirect to sign-in); a missing one returns
**404**. Hit a deliberately fake path as the control, or a 303 proves nothing.
