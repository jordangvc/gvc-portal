# Inventory — Field Guide (phone-length)

Open **Inventory** from the hub. Four big buttons. That's the tool.

## Drop off (bringing material IN)
1. Tap **Drop off** → scan the shelf/zone QR (or pick from the list).
2. Add what you're dropping: search it, tap a recent, or scan it.
3. Type how many + the unit (box, each, bucket…). Half a box = 0.5 box.
4. Everything lands in one cart. Check it. **Submit once.**

## Pick up (taking material OUT)
1. Tap **Pick up** → scan where you're taking it FROM.
2. Add items — the list shows what's actually there first.
3. Where's it going? **Me** is the first choice, or a truck / job.
4. Submit. If it says "only N left", the shelf and the app disagree —
   take what's there and run a Count, or get a manager.

## Transfer (truck ↔ storage ↔ job)
Scan FROM, scan TO, add everything moving — braces, boards, a ladder, a
whole scaffold kit — one cart, one submit. Toolroom tip: turn on
**Scan continuously** and beep each asset into the cart.

## Count
Open your assigned count. For each item: type what you actually see —
**0 is an answer, type it**. Can't count something? Skip it with a reason.
Submit when done. (On a blind audit you won't see the expected numbers —
that's on purpose.)

## Something's not in the app
Tap **Not listed** → photo → the name YOU call it → how many → done.
The office matches it up later. Don't force it into a wrong item.

## Something's broken or missing parts
From the item/asset (or after scanning it): **Report damage** → pick
what's wrong → photo → short note. It flags the office; it doesn't
delete anything.

## Weak signal
Keep working. Anything that can't send shows under **Pending sync** and
goes automatically when you're back in coverage. Pending means *not
confirmed yet* — if an entry turns red ("needs attention"), open it and
read why; fix or discard it. Never re-enter a pending transaction twice.

## Rules of thumb
- One physical trip = one submitted cart, even with 20 things on it.
- Scan when scanning is faster; type when typing is faster. Every label
  has its code printed on it for typing.
- If you moved it, record it. The app is only as honest as the moves.
